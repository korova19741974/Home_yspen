# Мой дом

Интерактивный прототип личной панели управления умным домом. Пока он работает в демо-режиме: кнопки меняют локальное состояние в браузере, а сценарии, пылесосы и музыкальные кнопки не обращаются к внешним сервисам.

## Что есть сейчас

- адаптивная карта двух этажей с комнатами и устройствами;
- управление светом и розетками в демо-режиме;
- сценарии «Спокойной ночи», «Никого нет дома» и уборка каждого этажа;
- карточки роботов Xiaomi M40, протечки и температуры;
- PWA-основа: панель можно установить как приложение из браузера;
- GitHub Pages workflow для бесплатного предпросмотра.

## Временный код демо

Прототип открывается кодом `[removed]`. Это только элемент оболочки: код находится в браузерном JavaScript и **не является защитой**. Перед публикацией панели или подключением устройств он будет заменён серверной авторизацией через Home Assistant, Tailscale или Cloudflare Access.

## Локальный запуск

Проект не требует установки зависимостей. В корне репозитория выполните:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Подключение дома позже

После развёртывания Home Assistant на Windows ПК интерфейс будет подключён к его API. Интеграции предполагаются такие:

1. Tuya / Smart Life — выключатели и розетки.
2. Zigbee-шлюз Smart Life — датчик протечки и температуры.
3. Xiaomi Home — роботы-пылесосы M40; сначала базовые команды, затем при возможности карта.
4. Yandex Station — тестовое управление музыкой через отдельную интеграцию.
5. Tailscale — доступ только для владельцев, без публикации панели в интернет.

Не добавляйте в репозиторий пароли, токены, резервные коды или файлы конфигурации Home Assistant.
